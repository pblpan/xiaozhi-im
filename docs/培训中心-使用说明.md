# 培训中心 · 使用说明

> 服务端 0.20.0 ／ 客户端 0.16.0 起可用。
> 入口：手机端「工作台 → 培训中心」；管理端左侧菜单「培训中心」。

---

## 一、这套东西解决什么问题

门店培训的痛点不是"没有资料"，是**不知道谁学了、学到哪、会不会**。
`Y:\培训资料` 里躺着 200+ 视频、200+ 课件，丢在共享盘里等于没培训。

所以这里做的是一条最小闭环：

```
课程 → 章节 → 课时（视频/文档，记进度）→ 章节考试（判分、留档）
```

管理端能看到 **谁学了、考了多少、过没过**。这一条才是重点 ——
没有它，前面做得再漂亮也只是个视频播放器。

---

## 二、三步把 200+ 素材变成课程

素材盘的结构决定了导入结果。导入器按**目录层级**自动建课：

```
Y:\培训资料\
  店长管理\                    ← 一级目录 = 课程分类
    01 门店日常管理\            ← 二级目录 = 课程
      01 早会怎么开.mp4         ← 文件   = 课时
      02 交接班.mp4
    02 人员管理\
  生鲜陈列\
    陈列基础\
```

### 第 1 步：先看会建成什么（不写库）

```bash
cd <项目目录>/server
node tools/import_training.js --dir "Y:\培训资料"
```

**默认就是预览，不写库**，只打印：会建几门课、每门课几个章节几节课时、哪些文件被跳过。
**先看这一步再动手** —— 素材盘里常混着 `.DS_Store`、`~$xxx.pptx` 这类垃圾，
以及年份/部门这种其实不该当课时名的目录。

### 第 2 步：真导入

```bash
node tools/import_training.js --dir "Y:\培训资料" --apply --copy
```

- `--apply` 才真写库；`--copy` 把文件复制进服务端的 `files` 目录。**不加就是把素材盘的绝对路径记进库**，
  也就是服务端必须能访问 `Y:`（NAS 上通常不行，建议加 `--copy`）。
  200G 素材全拷一份要留足空间，也可以分批按一级目录导。
- **重复导入是幂等的**：同一门课（分类+课程名）不会建第二份，同一个课时（标题）不会重复。
  所以"导一半断了"可以直接重跑，不会导出一堆重复课。

### 第 3 步：到管理端补结构和发布

导入只建"课程/章节/课时"骨架，**默认是草稿（学员看不到）**。到
管理端「培训中心 → 课程」：

1. 点「结构」检查章节课时对不对，改名/删多余的；
2. 课时没挂上课件的（结构里会标橙色「未挂课件」），点「改」或重建课时补上；
3. 加章节考试（见下一节）；
4. 确认没问题后点「**发布**」—— 学员侧这时才看得到。

## 三、建章节考试

管理端「结构 → + 考试」。三件事要理解清楚，它们都是**服务端强制的**：

| 规则 | 为什么 |
|---|---|
| **点「开始考试」就消耗一次机会** | 只在交卷时才算的话，学员可以点进去看一眼题目、退出、再点进去 —— 题目就漏光了，而且全程没有任何报错。考试页顶部会明说「已进入考试，本次机会已开始计算；中途退出不会退回」 |
| **本章进度不达标不放行** | "学完再考"是培训的意义。能跳过视频直接考，完成率这个数字就是假的，且假得看不出来。默认要求 100%（本章课时全部看完） |
| **多选题全对才得分** | 漏选、错选都 0 分。部分给分会诱导出"蒙几个选项"的玩法 |
| **历史成绩不随改题变化** | 判分在**提交那一刻**按当时的题目算并落库。老师之后改了一道题，老成绩不会集体漂移 |

建考试时题目和考试**一次提交建好**：分开建会出现"没有题的考试"，
学员点进去拿不到题、直接判 0 分，而界面上什么都看不出来。
所以界面在提交前会挡三道：有题干、每题至少两个选项、每题标了正确答案。

**正确答案只在管理端显示**，下发给学员的题目不带答案（带了就是开卷）。

## 四、看成绩

管理端「培训中心 → 成绩」：

- 按课程筛选、只看及格；
- 每人每场考试的**第几次**机会、分数、及格线、结果（及格/不及格/**未交卷**）；
- **不限时间** —— 去年的成绩也查得到（不会因为"默认只看最近 30 天"而静默消失）。

「未交卷」是一个要盯的状态：点了开始、没交就退出，这次机会就作废了。
成绩表里他会以"未交卷"出现，分数 0。

## 五、学员侧是什么样

手机端「工作台 → 培训中心」：

- **课程列表**：全部门店课程 / 我的课程（点「加入」收进自己的清单）；
- **课程详情**：章节按顺序排，每章显示进度条与考试入口；
  - 课时看过是实心对勾，没看过是播放圈；
  - **点课时**就把视频/文档下载到本机，**再用系统播放器打开**
    （不用内置播放器：门店货架边上信号差，先下完再看是唯一靠谱的方式；
    下过的不会重下，中途失败不会留半截文件被当成"已下载"）；
- **章节考试**：答题卡、题型分单选/多选/判断，交卷后当场出分并标出哪题错了；
  没达到进度门禁时点考试会明确告诉你"本章进度 xx%，还差多少"，
  而不是笼统地报"加载失败"。

## 六、常见问题

**Q：学员说看不到「培训中心」入口？**
入口由服务端下发。检查两件事：① 服务端版本 ≥ 0.20.0；② 客户端在工作模式
（个人模式下不显示作业类应用）。入口本身不需要"加入组织"就能看到 ——
临时帮忙的人、新来的店长都要能学。

**Q：课程建好了学员打开是空的？**
十有八九是没点「发布」（草稿态学员侧看不到）。管理端列表里状态列会显示「草稿」。

**Q：视频点开没反应 / 转圈？**
看管理端结构里那个课时是不是标着「未挂课件」。导入时如果素材盘断连，
课时会建成但没有文件；重新导入一次会补上。

**Q：进度百分比是不是"看完了多少"？**
不是。目前**「打开过」就算这一节完成** —— 没有内嵌播放器，拿不到"看到第几秒"，
所以「本章进度 100%」的准确含义是「本章每一节都点开过」。
这是本版有意接受的折中（先把闭环跑通），不是 bug。
要真正做到"看完才算"，得接内嵌播放器（`tr_progress.position_sec` 字段已经留好了）。
**别拿这个完成率去算工资或罚款**。

**Q：能改考试及格线或已发布的题目吗？**
能改。改完不影响历史成绩（判分口径已在提交时落库）。但**机会次数**改小
不会给已经用完的人补机会。

**Q：素材盘里有些目录不想导？**
先把它们从 `Y:\培训资料` 移出去，或导入后在管理端删掉对应课程。
有大量要过滤的东西时告诉小智，给导入器加排除规则。

小智扫码枪 · 使用说明

Android 版 v1.0.0 ｜ 独立离线扫码工具 ｜ 2026-09-19

一、这是什么

一个独立的小 App，专门用来拿手机 / 扫码枪把条码扫成一笔账，然后导出发给同事。

它和「小智 IM」是两个 App（包名不同），可以同时装在一台手机上，互不覆盖、互不影响。

装完就能用，不需要任何设置。这个 App 一次网络请求都不发 —— 不用输服务器地址、不用登录、不依赖厂里的网。商品资料靠导入一份表格带进去。

二、第一次使用：先导入商品档案

不导入也能扫，只是每个条码都会显示「未知条码」。要让手机认得商品，走这五步：

  1. 打开 App，点输入框右边那个「商档」按钮（图标像一摞盒子）。
  2. 先选 「导出商档模板（照着填）」 → 会生成一份表格文件，点「发给同事」发到电脑（或直接发给自己）。
  3. 用 Excel / WPS 打开模板，按这 4 列填：序号、条码、商品名字、数量。
  4. 填好的表格传回手机（微信发给自己就行）。
  5. 再点「商档」→ 「导入商档 CSV」 → 选那份文件。提示 商档已导入：N 个商品 就成了。

表格要求（认得很宽，不用改格式）

这一列表头可以叫这些名字（任选一个）
序号（可省）序号 —— 只给你对着纸质表核行号用，程序不读它，填不填都行
条码（必填）条码 / 条形码 / 商品条码 / 国际条码 / 商品编码 / 编码 / 货号 / PLU / barcode / code
商品名字商品名字 / 品名 / 商品名称 / 商品名 / 名称 / name
数量数量 / 账面数 / 账面数量 / 账面库存 / 系统库存 / 库存数 / 库存 / qty
  • 编码不用管：UTF-8 和 GBK（Excel 默认存出来的那种）都能读，直接导就行。
  • 条码不能空：空条码的行会被跳过，App 会告诉你跳了几行。
  • 只填「条码 + 商品名字」也够用；数量留空就是没有账面数（盈亏表里账面按 0 算）。
  • 表里多出几列（规格、单位、售价之类）也没事，照旧能导 —— 只是那几列不用填。
别把「扫码明细」当商档导回来。 导出的明细里也有「数量」一列，但那是你扫出来的实盘数； 当商档导进来会变成账面数，于是账面 = 实盘，盈亏表上差异全是 0 （看着"盘得特别准"，其实压根没比对过）。要盘下一轮，请重新导一次真正的商档。
注意：导入是「整份替换」，不是追加。 这一次文件里没有的条码，手机上原来的记录会被清掉。所以要导就导全量清单， 别拿一个分店的部分表去"补充"。

三、怎么扫

方式一：蓝牙 / 无线扫码枪（推荐，最快）

  1. 用手指点一下页面上方那个输入框，让光标停在里面。
  2. 拿枪对着条码按一下。枪扫出来的字会自己进输入框，并自动回车 —— 这一笔就记上了。
  3. 扫完接着扫下一件，不用再点输入框。
「扫了没反应」九成是光标不在输入框里。界面上表现为输入框没有光标 / 键盘收起来了。 再点一下那个输入框就能继续扫 —— 不用重启 App。

方式二：用手机摄像头

点左边蓝色的 「扫码」 按钮，对着条码即可。没带枪的时候用这个。

扫完给什么反馈

结果声音震动
记上了短促的一声「嘀」轻震一下
没记上 / 出错两声低音「嗡—嗡」重震一下

右上角的喇叭图标可以开关提示音（在冷柜旁边想静音时用）。震动一直开着 —— 现场吵的时候，震动是唯一能感觉到的反馈。

四、看结果 / 导出

  • 明细列表：序号 / 条码 / 数量 / 商品名称。点右边的垃圾桶删掉一行；点数量可以手工改（改成 0 就是删）。
  • 同一个条码扫两遍 = 数量累加（不是多出一行）。扫重了删掉一行或把数量改小。
  • 右上「盈亏表」：账面数 vs 实盘数、差异、金额。
  • 底部两个导出按钮：
    • 「导出文档」= .txt，微信里点开就能看
    • 「导出表格」= .csv，Excel / WPS 打开
  • 导出后会弹出选项，第一项就是「发给同事」 → 微信 / 企微 / 钉钉都直接列在里面。
表格里的条码列已经做过保护，用 Excel 打开是完整的 6921817824327，不会变成 6.92E+12 那种科学计数法。

五、扫码单

每次采集都落在一张扫码单上，单号形如 PD20260919150235（就是开始扫的时间）。

  • 点右上「切换 / 新建扫码单」可以新开一单，或者翻回以前某一单继续扫。
  • 导出是按单走的 —— 一张单一个文件，不会混在一起。
  • 「清空本单」会把这单的记录全删掉，删之前会问一次。

六、常见问题

现象怎么办
用扫码枪扫，屏幕上没反应先点一下输入框把光标点进去。还不行就看右上角提示音是不是被关了，把音量确认一下。
显示「未知条码」这个条码不在手机的商品档案里。先在「商档」里导一次 CSV。
导入失败，说「没读到任何商品」确认表里有一列叫「条码 / 商品条码 / PLU」之类的名字，并且那一列不是空的。也可以先「导出商档模板」照着做一份。
数量比自己数得多同一条码重复扫是累加数量。在列表里把数量改小，或删掉那行。
导出的表格打不开 / 乱码用 Excel 或 WPS 打开 .csv；手机上也可以用「导出文档」拿 .txt。
换了手机，数据不见了数据存在手机本地，不上传服务器。换机前先把明细导出发给自己。

七、内置商品档案（门店定制版才有）

有些版本把门店的商品档案直接打进了安装包，装上就有名字，不用自己导表。识别办法：打开 App 时第一屏会显示"正在装入商品档案"。

  • 只在第一次打开时装载，之后直接进采集页。装载 12 万条要十几秒，看着进度走完就行。
  • 如果你想换成自己导的表，照第二节导入即可 —— 导入会整份替换。
  • 导错了、导得不全，可以回「商档」→ 「恢复内置商品档案」换回安装包里自带的那份，不用卸载重装。
  • 内置档案不带账面数量（门店那份商品主档里没有库存列）。所以盈亏表里"账面"按 0 算，差异就等于实盘数 —— 这是正常的。要真正的账面数，另外导一份带数量的商档（第二节）。
  • 通用版（没有内置档案）不会出现这一屏，也不会有「恢复内置」这个菜单项。

八、这一版有意没做的（别当故障报）

  • 数据不回传服务器：采完导出、发出去，就是完整闭环。回传以后再加。
  • 没有账号 / 登录：员工装上就用。
  • 不做盘点制度：这里只负责"把条码扫成一笔账"。盘点位、初盘/复盘/抽盘那套是另一个模块，不在这台手机上。
